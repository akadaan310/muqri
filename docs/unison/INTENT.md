## Immutable boundaries
- Preserve the complete existing MUQRI recitation engine, acoustic/calibration/scoring reports, Qur'anic source texts, basmala handling, and research artifacts. Do not replace with an illustrative prototype.
- Preserve GLASS registry as authority. A pinned, reproducible mirror may be placed under UNISON for offline operation, with provenance and drift checks.
- Source orthography, token order and location, vowel/shadda, morphology, speech act, hypothesized numeric operator semantics, emitted phonemes, acoustics, and synthesized audio are distinct typed transformations.
- Qur'anic text / accepted qira'at remain authoritative within established MUQRI profiles; experimental interpretation cannot alter a Tajwid verdict.
- No Google searches, external theory validation, model download, external dataset ingestion, or production audio inference in this commission.
- A language not equipped with approved phonemic/prosodic resources yields an explicit UNKNOWN pronunciation rather than invented speaking.
- Maintain the original non-main working branch unchanged. Create main from the currently observed commit for owner-mandated main publication; do not change repository default settings.
- Add a stdlib-only 'unison' package, mathematical brief, fixtures, and an opt-in switchable legacy capability host. Leave legacy execution as default.

## Acceptance and refusal gates
- Exact source preservation even after analysis. No implicit hamza-to-alif in QITṬ.
- Positive and counterexample positional glyph decoding, 109 vs 118 shadda profiles, 280 vs 380 string formation, 999->1000->2000->1e6.
- No language independent G2P function is claimed; explicit language-specific lexica/adapters are required.
- Spoken form depends on lexical, syntactic, phonological, dialect/reading and prosodic context.
- Muqatta'at: LETTER_NAME reading cannot be silently reduced to ordinary syllabic word reading.
- Basmalah as independent passage vs embedded quote is source and verse-context tagged, never inferred from symbolic arithmetic.
- In shadow mode only pure capabilities execute both paths; unison mode is reversible at the dispatch layer.
- The repository's original acoustic / learner / measurements/1 contract must remain untouched.
- Scientific status and actually executed tests must be reported without inflation.
